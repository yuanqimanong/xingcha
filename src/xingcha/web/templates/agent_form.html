{# ---------------------------------------------------------- 输出保证 #}

输出保证

只影响 T2，不改变它的保证（校验与重试两边一样）。 有的上游没有 tools 这条路——DeepSeek 的思考模式就不接受 tool_choice， 用工具通道每次都 400。换成提示词通道即可；代价是模型对提示词里的 schema 遵守度略低，而那正是校验+重试要兜的东西。
档位的代价摆在这里由你选，而不是替你选最强的。T2 输出不合规时 自动重试（最坏调 1+{{ form.retries }} 次模型，token 按整轮计费）； T3 只把 schema 当提示，不做任何校验。
