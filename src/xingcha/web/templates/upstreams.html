切换会影响什么

你现有的 {{ agent_count }} 个 Agent 里写的是模型名（如 openai/gpt-5）。换上游之后那些模型可能不存在，对应的 Agent 会开始报错。 所以点「检查并切换」时会先用新 key 拉一次目录，把要失效的 Agent 列出来给你确认， 拉不通就直接拒绝切换。

裸模型直通不受影响——它把你给的 model 原样转发，换上游就是换了可用模型的集合。
