管理面的运行列表回答「跑了几次、花了多少、有没有报错」。它回答不了 「模型到底看到了什么、又吐回了什么」——而调提示词的时间几乎全花在那个问题上。 接上 Langfuse 就能看到每次调用的完整消息、重试与耗时。

这里只配地址，开关在每个 Agent 上。 填好之后，Agent 编辑页的「可观测」分区就能逐个勾选—— 一个跑客户合同的 Agent 与一个跑内部分类的 Agent，对"对话内容能不能离开这台 机器"的答案通常不一样，不该由一个全局开关统一。
