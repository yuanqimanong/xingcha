账号
这台星槎的全部用量

总闸。星槎是单管理员的，没有多用户体系，所以这一层实际就是 「全站合计」——包括直通裸模型的调用。

密钥
某一把 sk-xc- 的用量

按调用方分账。一个业务一把 key，哪个业务跑飞就只停哪个，别的照常。

Agent
某个 Agent 的用量，不分是谁调的

给贵的 Agent 单独封顶——结构化 Agent 最坏会调 1+重试次数 次模型，一次跑飞就是几倍的钱。

一次经过 Agent 的调用会同时记进「账号」「那把密钥」「那个 Agent」 三个计数器，任意一条超了就拒。所以常见配法是：账号设一个大的兜底，再给具体的 密钥或 Agent 设小的。
